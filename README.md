# 🎯 AI Student Performance Predictor

A full-stack web application that predicts student performance based on study habits using Machine Learning.

---

## 🚀 Live Demo

🌐 https://student-analytics-qv2d.onrender.com

---

## 🧠 Features

* 🔐 User Authentication (Signup/Login)
* 🎯 Predict student marks using ML model
* 📊 Analytics Dashboard (charts & insights)
* ☁️ Cloud Database (MongoDB Atlas)
* 🌐 Deployed on Render

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask (Python)
* **Database:** MongoDB Atlas
* **Machine Learning:** Scikit-learn
* **Deployment:** Render

## ⚙️ How It Works

1. User signs up / logs in
2. Enters study-related inputs (hours, sleep, attendance, etc.)
3. ML model predicts marks
4. Data is stored in MongoDB
5. Dashboard visualizes predictions

---

## 🧪 Run Locally

```bash
git clone https://github.com/sourabhchetan/student-analytics.git
cd student-analytics
pip install -r requirements.txt

# Set environment variable
set MONGO_URI=your_mongodb_connection_string

python run.py
```

---

## 🔐 Environment Variables

Create the following:

* `MONGO_URI` = MongoDB Atlas connection string
* `SECRET_KEY` = Any random string
